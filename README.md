# AI Study Assistant (StudyMate AI)

An intelligent study platform designed to help students learn smarter with PDFs, AI-powered explanations, structured notes, and interactive practice quizzes.

## Features

- **Study Dashboard**: Track learning streaks, recent materials, and study progress.
- **PDF & Document Library**: Organize and manage your study resources in one place.
- **AI Tutor**: Ask questions and get instant, easy-to-understand explanations tailored to your materials.
- **Smart Notes**: Create, organize, and review structured study notes.
- **Practice Quizzes**: Generate and take interactive quizzes to test your knowledge and track scores.
- **Study History**: Review past sessions, quiz attempts, and learning milestones.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Styling**: React 19, Tailwind CSS v4, Radix UI / shadcn/ui, Lucide Icons
- **State & Data**: TanStack React Query, React Hook Form, Zod
- **Testing**: Vitest & React Testing Library

## Getting Started

### Prerequisites

- Node.js (v18+ recommended) and npm

### Installation

```sh
git clone https://github.com/jatin8469/ai-study-assistant.git
cd ai-study-assistant
npm install
```

### Development

Start the development server:

```sh
npm run dev
```

### Build

Build the project for production:

```sh
npm run build
```

### Testing

Run the test suite:

```sh
npm run test
```
